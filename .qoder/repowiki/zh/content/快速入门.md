## 简介

TDengine 是一款高性能、分布式的时序数据库，专为物联网、监控、金融等场景设计。本快速入门指南旨在帮助新用户在10分钟内完成 TDengine 的安装、连接和第一个查询操作。涵盖 RPM、DEB、Docker 和源码编译等多种安装方式，并提供 C 和 Python 的连接与查询示例。

## 安装方式

### 使用RPM包安装（适用于CentOS/RedHat）

1. 下载适用于您系统的 RPM 包：
   ```bash
   wget https://www.taosdata.com/assets/publish/tdengine-3.0.0.0.rpm
   ```
2. 安装 RPM 包：
   ```bash
   sudo rpm -i tdengine-3.0.0.0.rpm
   ```

构建脚本 `makerpm.sh` 位于 `packaging/rpm/` 目录下，用于自动化生成 RPM 包。

**Section sources**
- [makerpm.sh](file://packaging/rpm/makerpm.sh#L1-L110)

### 使用DEB包安装（适用于Ubuntu/Debian）

1. 下载适用于您系统的 DEB 包：
   ```bash
   wget https://www.taosdata.com/assets/publish/tdengine-3.0.0.0.deb
   ```
2. 安装 DEB 包：
   ```bash
   sudo dpkg -i tdengine-3.0.0.0.deb
   ```

构建脚本 `makedeb.sh` 位于 `packaging/deb/` 目录下，负责复制二进制文件、配置文件并打包。

**Section sources**
- [makedeb.sh](file://packaging/deb/makedeb.sh#L1-L217)

### 使用Docker安装

1. 拉取官方镜像：
   ```bash
   docker pull tdengine/tdengine:3.0.0.0
   ```
2. 启动容器：
   ```bash
   docker run -d --name tdengine -p 6030:6030 tdengine/tdengine:3.0.0.0
   ```

Dockerfile 位于 `packaging/docker/` 目录，基于 Ubuntu 镜像，自动解压安装包并配置环境。

**Section sources**
- [Dockerfile](file://packaging/docker/Dockerfile#L1-L60)

### 源码编译安装

1. 克隆仓库：
   ```bash
   git clone https://github.com/taosdata/TDengine.git
   cd TDengine
   ```
2. 编译并安装：
   ```bash
   ./build.sh
   cd build && sudo make install
   ```

## 服务启动与验证

安装完成后，启动 TDengine 服务：

```bash
sudo systemctl start taosd
```

验证服务状态：

```bash
sudo systemctl status taosd
```

检查端口是否监听：

```bash
netstat -tuln | grep 6030
```

配置文件位于 `/etc/taos/taos.cfg`，可修改监听地址、日志路径等参数。

## Python语言连接示例

TDengine 提供 Python 连接器，可通过 `pip` 安装：

```bash
pip install taos
```

示例代码位于 `examples/python/read_example.py` 和 `PYTHONConnectorChecker/PythonChecker.py`，基本流程如下：

```python
import taos

# 建立连接
conn = taos.connect(host="localhost", user="root", password="taosdata", config="/etc/taos")

# 创建游标
cur = conn.cursor()

# 执行建库
cur.execute("CREATE DATABASE IF NOT EXISTS pydb")
cur.execute("USE pydb")

# 建表并插入数据
cur.execute("CREATE TABLE t (ts TIMESTAMP, value DOUBLE)")
cur.execute("INSERT INTO t VALUES (NOW, 12.5)")

# 查询数据
cur.execute("SELECT * FROM t")
results = cur.fetchall()
for row in results:
    print(row)

# 关闭连接
cur.close()
conn.close()
```

## 常见问题排查

### 服务无法启动

- 检查日志文件：`/var/log/taos/taosd.log`
- 确保端口 6030 未被占用：`netstat -tuln | grep 6030`
- 检查配置文件 `/etc/taos/taos.cfg` 是否正确
- 使用 `systemctl status taosd` 查看服务状态

### 连接被拒绝

- 确认 `taosd` 服务正在运行
- 检查防火墙是否放行 6030 端口
- 若远程连接，确保 `firstEp` 配置正确且网络可达
- 使用 `taos -h <host>` 指定主机连接

### Python连接失败

- 确保已安装 `taos` Python 包
- 确认 `libtaos.so` 在系统库路径中
- 检查 `LD_LIBRARY_PATH` 是否包含 `/usr/lib/taos`
- 使用 `conn = taos.connect(host="127.0.0.1")` 显式指定 IP
