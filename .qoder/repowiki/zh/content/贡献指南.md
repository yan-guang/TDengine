## 简介
TDengine 是一个高性能、分布式的时序数据库，致力于为开发者提供高效的数据存储与查询能力。我们欢迎所有开发者参与项目贡献，无论是代码改进、文档完善还是测试增强。本指南旨在帮助您快速了解如何参与 TDengine 的开发与维护，确保贡献过程顺畅高效。

## 贡献流程
要为 TDengine 项目做出贡献，请遵循以下步骤：

1. **签署贡献者许可协议（CLA）**  
   在提交代码前，您需要阅读并签署 [TaosData CLA](https://cla-assistant.io/taosdata/TDengine)。这是确保项目合法性和知识产权清晰的重要步骤。

2. **创建或关联 Issue**  
   所有功能添加或问题修复都应关联一个 GitHub Issue。如果尚未存在相关 Issue，请先在 [GitHub Issue Tracker](https://github.com/taosdata/TDengine/issues) 中创建一个新的 Issue。

3. **Fork 仓库并创建分支**  
   将 TDengine 仓库 Fork 到您的个人账户，并基于 `3.0` 开发分支创建新分支。请勿直接向 `main` 分支提交 Pull Request。

4. **提交 Pull Request (PR)**  
   完成代码修改后，发起 PR 将您的分支合并至 `3.0` 分支。PR 中请注明关联的 Issue 编号，以便团队审核。

5. **等待审核与反馈**  
   我们的开发团队将尽快审查您的 PR，并提供必要的反馈和建议。

## 代码风格与格式化
为保持代码库的一致性，TDengine 采用统一的代码风格规范。所有 C/C++ 源文件必须使用 `clang-format-14` 进行格式化。

### 使用 codeFormat.sh 脚本
项目提供自动化脚本 `tools/scripts/codeFormat.sh` 来格式化代码。该脚本会自动处理以下目录中的 `.c`, `.h`, `.cpp`, `.hpp` 文件：
- `include/`
- `source/os/`, `source/util/`, `source/common/`, `source/libs/`
- `source/client/inc/`, `source/client/src/`, `source/client/test/`
- `source/dnode/`

**注意**：`source/libs/parser/sql.c` 文件被排除在外，因其由生成器自动生成。

#### 执行方式
```bash
cd tools/scripts
./codeFormat.sh
```

此脚本将递归查找指定目录下的源文件并应用格式化规则，确保代码风格统一。

## 测试用例编写与运行
TDengine 使用 `taostest` 框架进行系统级测试，支持功能测试、性能测试和稳定性测试。

### 测试框架结构
`taostest` 位于 `test/new_test_framework/taostest/` 目录下，主要组件包括：
- `main.py`：测试入口点，解析命令行参数并启动测试框架。
- `components/taosd.py`：管理 `taosd` 服务的安装、配置、启动与销毁。
- `util/`：提供远程执行、文件操作、SQL 执行等通用工具。
- `performance/`：性能测试模块，支持基准测试与结果分析。

### 编写测试用例
测试用例通常以 Python 编写，继承自 `TaosTestFrame` 类，利用 `TDSql` 对象执行 SQL 命令并验证结果。

### 运行测试
通过 `taostest` 命令行工具运行测试，常用参数包括：
- `--setup`：部署测试环境
- `--use`：使用现有环境
- `--case`：指定测试用例
- `--concurrency`：设置并发数
- `--taosd-valgrind`：启用 Valgrind 内存检测

示例：
```bash
python -m taostest --test-root /tmp/test --setup --case test_insert
```

## 调试 taosd 服务
当 `taosd` 服务出现异常时，可使用以下方法进行调试：

### 使用 GDB 附加进程
项目提供 `test/tools/gdb.sh` 脚本，用于自动附加 GDB 到正在运行的 `taosd` 进程。

#### 脚本内容
```bash
#!/bin/bash

TAOSD_PID=$(ps -ef | grep -wi taosd | grep -v grep | awk '{print $2}' | head -n 1)

if [ -z "$TAOSD_PID" ]; then
    echo "Error: taosd process not found."
    exit 1
fi

gdb attach "$TAOSD_PID"
```

#### 使用方法
```bash
cd test/tools
./gdb.sh
```

该脚本会自动查找 `taosd` 进程 ID 并启动 GDB 进行调试，便于分析运行时状态和堆栈信息。

### 其他调试技巧
- 查看日志文件：默认位于 `/var/log/taos/taosdlog.*`
- 启用 ASAN（AddressSanitizer）检测内存错误
- 使用 `valgrind` 进行内存泄漏检测（通过 `taostest --taosd-valgrind` 启用）
