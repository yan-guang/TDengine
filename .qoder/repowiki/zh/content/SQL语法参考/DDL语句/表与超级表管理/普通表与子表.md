## 普通表与子表概述
在TDengine中，表分为普通表和子表。普通表用于存储非时序数据，而子表则继承自超级表，用于存储时序数据。超级表定义了子表的结构，包括列定义和标签（TAGS）定义。子表通过继承超级表的结构，可以高效地管理海量设备数据。

## 创建表
### 创建普通表
创建普通表使用`CREATE TABLE`语句，语法如下：
```sql
CREATE TABLE [IF NOT EXISTS] table_name (column_def_list) [table_options];
```
其中，`column_def_list`定义了表的列，`table_options`定义了表的选项。

### 创建子表
创建子表使用`CREATE TABLE`语句，但需要指定其所属的超级表和标签值，语法如下：
```sql
CREATE TABLE [IF NOT EXISTS] table_name USING super_table_name TAGS (tag_values);
```
其中，`super_table_name`是超级表的名称，`tag_values`是标签的值。

## 修改表
### 修改普通表
`ALTER TABLE`命令支持对普通表进行多种修改操作，包括添加/删除列、修改列名等。语法如下：
```sql
ALTER TABLE table_name ADD COLUMN column_name type_name;
ALTER TABLE table_name DROP COLUMN column_name;
ALTER TABLE table_name RENAME COLUMN old_column_name TO new_column_name;
```

### 修改子表
对于子表，`ALTER TABLE`命令同样支持添加/删除列、修改列名等操作。此外，还可以修改标签值：
```sql
ALTER TABLE table_name SET TAG tag_name = new_tag_value;
```

## 删除表
删除表使用`DROP TABLE`语句，语法如下：
```sql
DROP TABLE [IF EXISTS] table_name;
```
对于子表，也可以使用`DROP TABLE`语句进行删除。

## 超级表与子表继承机制
子表通过继承超级表的列定义，可以高效地管理海量设备数据。超级表定义了子表的结构，包括列定义和标签（TAGS）定义。子表在创建时，只需指定其所属的超级表和标签值，即可继承超级表的结构。这种设计在管理海量设备数据时具有显著优势，可以减少重复定义，提高数据管理效率。
