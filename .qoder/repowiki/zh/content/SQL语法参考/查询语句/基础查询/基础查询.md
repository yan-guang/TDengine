## 简介
本文档旨在基于 `sql.y` 语法文件，系统性地文档化 TDengine 数据库中 `SELECT` 语句的核心子句。文档详细说明了每个子句的语法规则、支持的操作符和数据类型，并提供了从简单到复杂的查询示例。所有内容均通过 `test/cases/20-DataQuerying` 目录下的相关测试用例进行验证，以确保准确性。

## SELECT 子句（选择列表）

`SELECT` 子句定义了查询结果中要返回的列或表达式，也称为“选择列表”。

### 语法规则
根据 `sql.y` 文件，`SELECT` 子句的语法定义如下：
```sql
query_specification ::= SELECT hint_list set_quantifier_opt tag_mode_opt select_list from_clause_opt where_clause_opt ...
```
其中 `select_list` 是核心部分，其定义为：
```sql
select_list ::= select_item | select_list ',' select_item
```
`select_item` 可以是：
- `*`：选择所有列。
- `table_name.*`：选择指定表的所有列。
- `common_expression`：一个通用表达式（如列名、函数、算术运算等）。
- `common_expression column_alias` 或 `common_expression AS column_alias`：为表达式指定别名。

### 支持的操作符和数据类型
`SELECT` 子句支持在表达式中使用多种操作符，包括：
- **算术运算符**：`+`, `-`, `*`, `/`
- **标量函数**：如 `NOW()`, `COUNT()`, `SUM()` 等。
- **常量和字面量**：可以返回常量值，如字符串 `'abc'` 或数字 `1`。

数据类型包括 `INT`, `FLOAT`, `DOUBLE`, `BINARY`, `TIMESTAMP` 等，这些在 `type_name` 规则中有定义。

### 查询示例
```sql
-- 选择特定列
SELECT ts, temperature FROM weather_stable;

-- 使用算术运算
SELECT temperature + 10 AS temp_plus_10 FROM weather_stable;

-- 使用聚合函数
SELECT COUNT(*), AVG(temperature) FROM weather_stable;

-- 选择常量
SELECT 'sensor_data' AS source, temperature FROM weather_stable;
```

## FROM 子句（数据源）

`FROM` 子句指定了查询的数据源，即要从中检索数据的表或子查询。

### 语法规则
`FROM` 子句是可选的，其语法定义为：
```sql
from_clause_opt ::= | FROM table_reference_list
```
`table_reference_list` 可以包含一个或多个表引用，用逗号分隔。表引用可以是：
- 普通表名或带数据库前缀的表名。
- 子查询。
- 连接表。

### 支持的数据源类型
- **普通表 (Table)**：直接指定表名。
- **超级表 (STable)**：作为数据源，通常与 `WHERE` 子句中的标签条件结合使用。
- **子查询 (Subquery)**：将一个查询的结果作为另一个查询的数据源。

### 查询示例
```sql
-- 从单个表查询
SELECT * FROM weather_stable;

-- 从多个表查询（隐式连接）
SELECT t1.ts, t2.value FROM table1 t1, table2 t2 WHERE t1.id = t2.id;

-- 从子查询结果查询
SELECT avg_temp FROM (SELECT AVG(temperature) AS avg_temp FROM weather_stable) sub;
```

## WHERE 子句（过滤条件）

`WHERE` 子句用于指定过滤条件，只有满足这些条件的行才会被包含在结果集中。

### 语法规则
`WHERE` 子句的语法定义为：
```sql
where_clause_opt ::= | WHERE search_condition
```
`search_condition` 是一个布尔表达式，其核心是 `predicate`，支持以下操作：
- **比较操作符**：`<`, `>`, `<=`, `>=`, `=`, `!=`, `<>`
- **逻辑操作符**：`AND`, `OR`, `NOT`
- **特殊谓词**：`BETWEEN ... AND ...`, `IS NULL`, `IS NOT NULL`, `IN (...)`

### 支持的操作符和数据类型
根据 `sql.y` 文件，`compare_op` 定义了所有比较操作符：
```sql
%type compare_op { EOperatorType }
compare_op(A) ::= NK_LT. { A = OP_TYPE_LOWER_THAN; }
compare_op(A) ::= NK_GT. { A = OP_TYPE_GREATER_THAN; }
...
```
此外，还支持 `LIKE`, `REGEXP`, `CONTAINS` 等操作符。数据类型方面，支持对所有基本数据类型进行比较。

### 查询示例
```sql
-- 比较过滤
SELECT * FROM weather_stable WHERE temperature > 30;

-- 逻辑组合
SELECT * FROM weather_stable WHERE temperature > 30 AND humidity < 80;

-- 使用 IN 和 BETWEEN
SELECT * FROM weather_stable WHERE location_id IN (1, 2, 3);
SELECT * FROM weather_stable WHERE ts BETWEEN '2023-01-01' AND '2023-01-31';

-- 标签过滤
SELECT * FROM weather_stable WHERE location = 'Beijing';
```

## GROUP BY 子句（分组）

`GROUP BY` 子句用于将具有相同值的行分组，通常与聚合函数（如 `COUNT`, `SUM`, `AVG`）一起使用。

### 语法规则
`GROUP BY` 子句的语法定义为：
```sql
group_by_clause_opt ::= | GROUP BY group_by_list
```
`group_by_list` 是一个由逗号分隔的表达式列表：
```sql
group_by_list ::= expr_or_subquery | group_by_list ',' expr_or_subquery
```

### 支持的数据类型和聚合函数
`GROUP BY` 可以基于任何表达式进行分组，包括列名、标签、时间窗口函数等。常用的聚合函数有 `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`。

### 查询示例
```sql
-- 按标签分组
SELECT location, AVG(temperature) FROM weather_stable GROUP BY location;

-- 按时间分组（结合时间窗口）
SELECT location, AVG(temperature) FROM weather_stable 
GROUP BY location, INTERVAL(1h);

-- 按多个列分组
SELECT location, device_id, AVG(temperature) FROM weather_stable 
GROUP BY location, device_id;
```

## ORDER BY 子句（排序）

`ORDER BY` 子句用于对查询结果进行排序。

### 语法规则
`ORDER BY` 子句的语法定义为：
```sql
order_by_clause_opt ::= | ORDER BY sort_specification_list
```
`sort_specification_list` 是一个排序规范列表：
```sql
sort_specification_list ::= sort_specification | sort_specification_list ',' sort_specification
```
每个 `sort_specification` 包含一个表达式和可选的排序方向（`ASC` 或 `DESC`）以及空值排序（`NULLS FIRST` 或 `NULLS LAST`）。

### 支持的排序选项
- **排序方向**：`ASC` (升序，默认), `DESC` (降序)。
- **空值处理**：`NULLS FIRST`, `NULLS LAST`。

### 查询示例
```sql
-- 按时间戳升序排序
SELECT * FROM weather_stable ORDER BY ts ASC;

-- 按温度降序排序，空值排在最后
SELECT * FROM weather_stable ORDER BY temperature DESC NULLS LAST;

-- 按多个列排序
SELECT * FROM weather_stable ORDER BY location ASC, temperature DESC;
```

## 综合查询示例
以下是一个结合了所有核心子句的复杂查询示例：
```sql
SELECT 
    location, 
    AVG(temperature) AS avg_temp, 
    MAX(humidity) AS max_humidity
FROM 
    weather_stable 
WHERE 
    ts >= '2023-01-01' 
    AND ts < '2023-02-01' 
    AND temperature IS NOT NULL
GROUP BY 
    location
HAVING 
    avg_temp > 20
ORDER BY 
    avg_temp DESC
LIMIT 10;
```
此查询：
1.  **FROM**: 从 `weather_stable` 超级表获取数据。
2.  **WHERE**: 过滤出2023年1月的数据，并排除温度为空的记录。
3.  **SELECT**: 计算每个分组的平均温度和最高湿度。
4.  **GROUP BY**: 按 `location` 标签进行分组。
5.  **HAVING**: 进一步过滤，只保留平均温度大于20的分组。
6.  **ORDER BY**: 按平均温度降序排列结果。
7.  **LIMIT**: 限制结果为前10条。
