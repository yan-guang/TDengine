## 简介
时间窗口功能是时序数据库中用于处理连续时序数据流的核心特性。通过将数据流分割成固定的时间间隔块，可以对每个时间块内的数据进行聚合分析，如计算每5分钟的平均温度。本文档基于`sql.y`语法文件，详细解释`INTERVAL`子句的语法结构、时间单位和滑动步长的使用方法，并提供具体的SQL示例和测试用例验证。

## 语法结构
`INTERVAL`子句用于定义时间窗口的大小和滑动步长。其基本语法如下：
```sql
INTERVAL (interval_duration [, offset_duration]) [SLIDING sliding_duration]
```
其中，`interval_duration`表示时间窗口的大小，`offset_duration`表示时间窗口的偏移量，`sliding_duration`表示滑动步长。

## 时间单位
时间单位用于指定时间窗口和滑动步长的大小，支持以下单位：
- `s`：秒
- `m`：分钟
- `h`：小时
- `d`：天
- `w`：周
- `n`：月
- `y`：年

**Section sources**

## 滑动步长
滑动步长（SLIDING）用于定义时间窗口的滑动间隔。如果未指定滑动步长，则时间窗口为固定窗口，每个窗口之间没有重叠。如果指定了滑动步长，则时间窗口为滑动窗口，每个窗口之间有重叠。

## 核心作用
时间窗口功能的核心作用是将连续的时序数据流分割成固定的时间间隔块，以便进行聚合分析。例如，可以计算每5分钟的平均温度、每小时的最大值等。通过使用`INTERVAL`子句，可以灵活地定义时间窗口的大小和滑动步长，满足不同的分析需求。

## SQL示例
以下是一些使用`INTERVAL`子句的SQL示例：

1. 计算每分钟的平均温度：
```sql
SELECT AVG(temperature) FROM temperature_table INTERVAL(1m)
```

2. 计算每5分钟的平均温度，滑动步长为1分钟：
```sql
SELECT AVG(temperature) FROM temperature_table INTERVAL(5m) SLIDING(1m)
```

3. 计算每天的最大温度，偏移量为2小时：
```sql
SELECT MAX(temperature) FROM temperature_table INTERVAL(1d, 2h)
```
