## 填充模式概述
填充模式用于在时间序列数据查询中处理时间窗口内的缺失数据点。当数据在指定的时间间隔内没有记录时，填充模式决定了如何处理这些缺失值。`FILL`子句支持多种填充策略，每种策略都有其特定的应用场景和行为。

**Section sources**
- [sql.y](file://source/libs/parser/inc/sql.y#L0-L799)

## 填充模式类型
### NONE
`NONE`填充模式表示不进行任何填充。当时间窗口内没有数据时，查询结果中不会包含该时间窗口的记录。

### NULL
`NULL`填充模式将缺失的数据点填充为`NULL`值。这种模式适用于需要明确表示数据缺失的场景。

### PREV
`PREV`填充模式使用前一个有效数据点的值来填充缺失的数据点。这种模式适用于数据变化较为平缓的场景。

### LINEAR
`LINEAR`填充模式通过线性插值来填充缺失的数据点。它使用前后两个有效数据点的值进行线性计算，生成中间缺失值。这种模式适用于数据变化较为规律的场景。

### VALUE
`VALUE`填充模式允许用户指定一个具体的值来填充所有缺失的数据点。这种模式适用于需要统一填充特定值的场景。

## 填充模式行为分析
### NONE 模式
在`NONE`模式下，查询结果仅包含实际存在的数据点。如果某个时间窗口内没有数据，该时间窗口不会出现在结果中。

### NULL 模式
在`NULL`模式下，所有缺失的数据点都会被填充为`NULL`。这使得查询结果中每个时间窗口都有记录，但缺失的数据点明确表示为`NULL`。

### PREV 模式
在`PREV`模式下，系统会查找前一个有效数据点的值，并用该值填充当前缺失的数据点。如果在查询范围内没有前一个有效数据点，则该位置仍为`NULL`。

### LINEAR 模式
在`LINEAR`模式下，系统会使用前后两个有效数据点的值进行线性插值。计算公式为：`value = y1 + (y2 - y1) * (x - x1) / (x2 - x1)`，其中`(x1, y1)`和`(x2, y2)`是前后两个有效数据点的坐标，`x`是当前缺失数据点的时间戳。

### VALUE 模式
在`VALUE`模式下，用户可以指定一个具体的值来填充所有缺失的数据点。这个值可以是数字、字符串或其他支持的数据类型。
