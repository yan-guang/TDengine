## 标量函数

本节文档化TDengine支持的标量函数，这些函数对单个值进行操作并返回单个值。

### ABS
- **函数签名**: `ABS(expr)`
- **参数说明**: `expr` - 一个数值表达式。
- **返回值类型**: 与输入类型相同的数值类型。
- **功能描述**: 返回指定数值表达式的绝对值。
- **示例**:
  ```sql
  SELECT ABS(-10) FROM table_name;
  ```
- **相关测试用例**: [test_fun_sca_abs.py](file://test/cases/22-Functions/01-Scalar/test_fun_sca_abs.py)

### LOWER
- **函数签名**: `LOWER(str)`
- **参数说明**: `str` - 一个字符串表达式。
- **返回值类型**: 字符串类型。
- **功能描述**: 将字符串中的所有字符转换为小写。
- **示例**:
  ```sql
  SELECT LOWER('HELLO') FROM table_name;
  ```
- **相关测试用例**: [test_fun_sca_lower.py](file://test/cases/22-Functions/01-Scalar/test_fun_sca_lower.py)

### UPPER
- **函数签名**: `UPPER(str)`
- **参数说明**: `str` - 一个字符串表达式。
- **返回值类型**: 字符串类型。
- **功能描述**: 将字符串中的所有字符转换为大写。
- **示例**:
  ```sql
  SELECT UPPER('hello') FROM table_name;
  ```
- **相关测试用例**: [test_fun_sca_upper.py](file://test/cases/22-Functions/01-Scalar/test_fun_sca_upper.py)

## 聚合函数

本节文档化TDengine支持的聚合函数，这些函数对一组值进行操作并返回单个值。

### COUNT
- **函数签名**: `COUNT(*)` 或 `COUNT(expr)`
- **参数说明**: `expr` - 一个表达式，`*` 表示所有行。
- **返回值类型**: BIGINT。
- **功能描述**: 返回指定表达式或所有行的数量。
- **示例**:
  ```sql
  SELECT COUNT(*) FROM table_name;
  ```
- **相关测试用例**: [count_test.sql](file://test/cases/22-Functions/02-Aggregate/count_test.sql)

### SUM
- **函数签名**: `SUM(expr)`
- **参数说明**: `expr` - 一个数值表达式。
- **返回值类型**: DOUBLE、BIGINT 或 UBIGINT。
- **功能描述**: 返回指定数值表达式中所有值的总和。
- **示例**:
  ```sql
  SELECT SUM(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_agg_sum.py](file://test/cases/22-Functions/02-Aggregate/test_fun_agg_sum.py)

### AVG
- **函数签名**: `AVG(expr)`
- **参数说明**: `expr` - 一个数值表达式。
- **返回值类型**: DOUBLE。
- **功能描述**: 返回指定数值表达式中所有值的平均值。
- **示例**:
  ```sql
  SELECT AVG(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_agg_avg.py](file://test/cases/22-Functions/02-Aggregate/test_fun_agg_avg.py)

### STDDEV
- **函数签名**: `STDDEV(expr)`
- **参数说明**: `expr` - 一个数值表达式。
- **返回值类型**: DOUBLE。
- **功能描述**: 返回指定数值表达式中所有值的标准差。
- **示例**:
  ```sql
  SELECT STDDEV(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_agg_stddev.py](file://test/cases/22-Functions/02-Aggregate/test_fun_agg_stddev.py)

## 选择函数

本节文档化TDengine支持的选择函数，这些函数用于从一组值中选择特定的值。

### FIRST
- **函数签名**: `FIRST(expr)`
- **参数说明**: `expr` - 一个表达式。
- **返回值类型**: 与输入类型相同。
- **功能描述**: 返回指定表达式在时间序列中的第一个值。
- **示例**:
  ```sql
  SELECT FIRST(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_select_first.py](file://test/cases/22-Functions/03-Selection/test_fun_select_first.py)

### LAST
- **函数签名**: `LAST(expr)`
- **参数说明**: `expr` - 一个表达式。
- **返回值类型**: 与输入类型相同。
- **功能描述**: 返回指定表达式在时间序列中的最后一个值。
- **示例**:
  ```sql
  SELECT LAST(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_select_last.py](file://test/cases/22-Functions/03-Selection/test_fun_select_last.py)

### TOP
- **函数签名**: `TOP(expr, k)`
- **参数说明**: 
  - `expr` - 一个数值表达式。
  - `k` - 返回的最大值数量。
- **返回值类型**: 与输入类型相同。
- **功能描述**: 返回指定数值表达式中最大的 `k` 个值。
- **示例**:
  ```sql
  SELECT TOP(value, 3) FROM table_name;
  ```
- **相关测试用例**: [test_fun_select_top.py](file://test/cases/22-Functions/03-Selection/test_fun_select_top.py)

### BOTTOM
- **函数签名**: `BOTTOM(expr, k)`
- **参数说明**: 
  - `expr` - 一个数值表达式。
  - `k` - 返回的最小值数量。
- **返回值类型**: 与输入类型相同。
- **功能描述**: 返回指定数值表达式中最小的 `k` 个值。
- **示例**:

## 时序函数

本节文档化TDengine支持的时序函数，这些函数用于处理时间序列数据。

### DIFF
- **函数签名**: `DIFF(expr)`
- **参数说明**: `expr` - 一个数值或时间戳表达式。
- **返回值类型**: BIGINT 或 DOUBLE。
- **功能描述**: 返回指定表达式中相邻值之间的差值。
- **示例**:
  ```sql
  SELECT DIFF(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_ts_diff.py](file://test/cases/22-Functions/04-Timeseries/test_fun_ts_diff.py)

### IRATE
- **函数签名**: `IRATE(expr)`
- **参数说明**: `expr` - 一个数值表达式。
- **返回值类型**: DOUBLE。
- **功能描述**: 返回指定数值表达式中相邻值之间的瞬时增长率。
- **示例**:
  ```sql
  SELECT IRATE(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_ts_irate.py](file://test/cases/22-Functions/04-Timeseries/test_fun_ts_irate.py)

### TWA
- **函数签名**: `TWA(expr)`
- **参数说明**: `expr` - 一个数值表达式。
- **返回值类型**: DOUBLE。
- **功能描述**: 返回指定数值表达式的时间加权平均值。
- **示例**:
  ```sql
  SELECT TWA(value) FROM table_name;
  ```
- **相关测试用例**: [test_fun_ts_twa.py](file://test/cases/22-Functions/04-Timeseries/test_fun_ts_twa.py)
