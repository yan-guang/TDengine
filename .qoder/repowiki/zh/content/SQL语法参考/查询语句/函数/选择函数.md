## 核心选择函数
TDengine支持多种选择函数，用于从时间序列数据中提取特定的数据点。这些函数包括但不限于`FIRST`、`LAST`、`TOP`、`BOTTOM`和`SAMPLE`。每个函数都有其独特的用途和行为，适用于不同的数据查询需求。

## FIRST函数
`FIRST`函数用于返回指定列中的第一个非NULL值。该函数在处理时间序列数据时特别有用，因为它可以快速获取某个时间段内的初始状态或值。

### 函数签名
```sql
FIRST(column_name)
```

### 参数说明
- `column_name`: 指定要查询的列名。

### 返回值类型
- 返回指定列中第一个非NULL值的数据类型。

### 功能描述
`FIRST`函数会遍历指定列的所有值，直到找到第一个非NULL值并返回。如果整个列都是NULL值，则返回NULL。

### SQL示例
```sql
SELECT FIRST(value) FROM temperature WHERE ts >= '2023-01-01 00:00:00' AND ts < '2023-01-02 00:00:00';
```

### 处理NULL值和时间戳的行为
`FIRST`函数在处理NULL值时，会跳过所有NULL值，直到找到第一个非NULL值。对于时间戳，`FIRST`函数会按照时间顺序查找，确保返回的是时间上最早的非NULL值。

## LAST函数
`LAST`函数用于返回指定列中的最后一个非NULL值。与`FIRST`函数类似，`LAST`函数在处理时间序列数据时也非常有用，可以快速获取某个时间段内的最终状态或值。

### 函数签名
```sql
LAST(column_name)
```

### 参数说明
- `column_name`: 指定要查询的列名。

### 返回值类型
- 返回指定列中最后一个非NULL值的数据类型。

### 功能描述
`LAST`函数会遍历指定列的所有值，直到找到最后一个非NULL值并返回。如果整个列都是NULL值，则返回NULL。

### SQL示例
```sql
SELECT LAST(value) FROM temperature WHERE ts >= '2023-01-01 00:00:00' AND ts < '2023-01-02 00:00:00';
```

### 处理NULL值和时间戳的行为
`LAST`函数在处理NULL值时，会跳过所有NULL值，直到找到最后一个非NULL值。对于时间戳，`LAST`函数会按照时间顺序查找，确保返回的是时间上最晚的非NULL值。

## TOP和BOTTOM函数
`TOP`和`BOTTOM`函数用于返回指定列中的最大值和最小值。这两个函数在分析数据极值时非常有用，可以帮助用户快速识别数据中的异常情况。

### 函数签名
```sql
TOP(column_name, n)
BOTTOM(column_name, n)
```

### 参数说明
- `column_name`: 指定要查询的列名。
- `n`: 指定返回的最大或最小值的数量。

### 返回值类型
- 返回指定列中前n个最大值或最小值的数据类型。

### 功能描述
`TOP`函数返回指定列中前n个最大值，而`BOTTOM`函数返回指定列中前n个最小值。如果列中有重复值，这些值也会被包含在结果中。

### SQL示例
```sql
SELECT TOP(value, 5) FROM temperature WHERE ts >= '2023-01-01 00:00:00' AND ts < '2023-01-02 00:00:00';
SELECT BOTTOM(value, 5) FROM temperature WHERE ts >= '2023-01-01 00:00:00' AND ts < '2023-01-02 00:00:00';
```

## 监控与告警中的应用
选择函数在监控和告警场景中有着广泛的应用。例如，`FIRST`和`LAST`函数可以用于监控系统的初始状态和最终状态，确保系统在运行期间没有发生异常。`TOP`和`BOTTOM`函数可以用于检测数据中的极值，及时发现潜在的问题。

### 示例
假设我们有一个温度传感器网络，需要监控每个传感器的温度变化。我们可以使用`FIRST`和`LAST`函数来获取每个传感器在一天内的初始温度和最终温度，以确保温度变化在正常范围内。

```sql
SELECT sensor_id, FIRST(temperature) AS initial_temp, LAST(temperature) AS final_temp 
FROM temperature 
WHERE ts >= '2023-01-01 00:00:00' AND ts < '2023-01-02 00:00:00' 
GROUP BY sensor_id;
```

### 告警规则
我们可以设置告警规则，当某个传感器的温度变化超过预设阈值时，触发告警。

```sql
SELECT sensor_id, ABS(LAST(temperature) - FIRST(temperature)) AS temp_change 
FROM temperature 
WHERE ts >= '2023-01-01 00:00:00' AND ts < '2023-01-02 00:00:00' 
GROUP BY sensor_id 
HAVING temp_change > 10;
```
