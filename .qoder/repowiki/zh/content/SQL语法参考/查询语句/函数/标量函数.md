## 引言
TDengine支持丰富的标量函数，这些函数在查询中对每一行数据独立计算并返回单个值。本参考文档全面介绍了TDengine支持的所有标量函数，包括其精确的函数签名、参数说明、返回值类型和功能描述。每个函数都通过具体的SQL代码示例展示用法，并链接到相关测试用例以验证其行为。

**Section sources**
- [scalar.h](file://include/libs/scalar/scalar.h#L39-L74)

## 标量函数执行方式
标量函数在TDengine查询中的执行方式是针对每一行数据独立计算。当查询包含标量函数时，数据库引擎会逐行处理结果集，将函数应用于每一行的相应列值，并将计算结果作为新列返回。这种执行模式确保了函数的计算是独立的，不会受到其他行数据的影响。

标量函数的执行由`scalarCalculate`函数在`scalar.h`中定义，并在`sclfunc.c`中实现各种具体函数。这些函数接收输入参数，执行计算，并将结果存储在输出参数中。

## 数学函数

### ABS
返回数值的绝对值。

**函数签名**
```sql
ABS(numeric_expression)
```

**参数说明**
- `numeric_expression`: 数值表达式，可以是TINYINT、SMALLINT、INT、BIGINT、FLOAT或DOUBLE类型。

**返回值类型**
与输入参数相同的数据类型。

**功能描述**
计算并返回给定数值的绝对值。对于NULL输入，返回NULL。

**SQL示例**
```sql
SELECT ABS(-10), ABS(5.5), ABS(NULL) FROM table_name;
```

### ROUND
对数值进行四舍五入。

**函数签名**
```sql
ROUND(numeric_expression [, decimal_places])
```

**参数说明**
- `numeric_expression`: 要四舍五入的数值表达式。
- `decimal_places`: 可选参数，指定要保留的小数位数，默认为0。

**返回值类型**
DOUBLE类型。

**功能描述**
将数值表达式四舍五入到指定的小数位数。如果未指定小数位数，则四舍五入到最接近的整数。

**SQL示例**
```sql
SELECT ROUND(3.14159), ROUND(3.14159, 2), ROUND(-2.718, 1) FROM table_name;
```

### LOG
计算数值的对数。

**函数签名**
```sql
LOG(numeric_expression [, base])
```

**参数说明**
- `numeric_expression`: 要计算对数的数值表达式。
- `base`: 可选参数，指定对数的底数，默认为自然对数(e)。

**返回值类型**
DOUBLE类型。

**功能描述**
计算数值的对数。如果只提供一个参数，则计算自然对数；如果提供两个参数，则计算以第二个参数为底的对数。

**SQL 示例**
```sql
SELECT LOG(10), LOG(100, 10), LOG(8, 2) FROM table_name;
```

## 使用场景
标量函数在TDengine中有广泛的应用场景：

**数据清洗**
