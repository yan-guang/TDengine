## 简介
TDengine是一款专为时序数据设计的高性能数据库，其内置了丰富的聚合函数以支持复杂的数据分析需求。本参考文档旨在全面介绍TDengine支持的核心聚合函数，包括`COUNT`、`SUM`、`AVG`、`MAX`、`MIN`以及专为时序数据优化的`TWA`（时间加权平均）等。文档将详细阐述每个函数的精确签名、参数说明、返回值类型和功能描述，并通过SQL代码示例展示其用法，特别是与`GROUP BY`子句的结合使用。重点将放在`TWA`函数如何在处理不规则采样或稀疏时序数据时提供更准确的平均值计算。

## 核心聚合函数
TDengine的核心聚合函数遵循标准的SQL语义，但针对时序数据的特点进行了优化。这些函数在计算时会自动忽略空值（NULL），并且能够高效地利用预计算的统计信息（如SMA，Superblock Metadata Aggregation）来加速查询。

### COUNT函数
`COUNT`函数用于计算指定列中非空值的数量。

- **函数签名**: `COUNT([* | column_name])`
- **参数说明**: 
  - `*`: 计算所有行的数量，包括包含空值的行。
  - `column_name`: 计算指定列中非空值的数量。
- **返回值类型**: `BIGINT`
- **功能描述**: 返回满足条件的行数或非空值的数量。

### SUM函数
`SUM`函数用于计算指定数值列所有非空值的总和。

- **函数签名**: `SUM(column_name)`
- **参数说明**: `column_name`：一个数值类型的列（整数、浮点数、无符号整数）。
- **返回值类型**: 与输入列类型匹配的数值类型（如`DOUBLE`、`BIGINT`）。
- **功能描述**: 返回指定列所有非空值的算术和。

### AVG函数
`AVG`函数用于计算指定数值列所有非空值的算术平均值。

- **函数签名**: `AVG(column_name)`
- **参数说明**: `column_name`：一个数值类型的列。
- **返回值类型**: `DOUBLE`
- **功能描述**: 返回指定列所有非空值的总和除以非空值的数量。

### MAX和MIN函数
`MAX`和`MIN`函数分别用于找出指定列中的最大值和最小值。

- **函数签名**: `MAX(column_name)` / `MIN(column_name)`
- **参数说明**: `column_name`：一个支持比较的列（数值、字符串、时间戳）。
- **返回值类型**: 与输入列类型相同。
- **功能描述**: 返回指定列中所有非空值的最大值或最小值。

## TWA函数详解
`TWA`（Time-Weighted Average）函数是TDengine为时序数据量身定制的核心聚合函数，它通过考虑数据点之间的时间间隔来计算加权平均值，从而在处理不规则采样或数据稀疏的场景下提供比简单算术平均更准确的结果。

### 函数签名与参数
- **函数签名**: `TWA(column_name)`
- **参数说明**: `column_name`：一个数值类型的列，其对应的主时间戳列将用于计算时间权重。
- **返回值类型**: `DOUBLE`
- **功能描述**: `TWA`函数假设数据点之间的值是线性变化的。它通过计算每个数据点与其下一个数据点之间形成的梯形面积，然后将所有梯形面积相加，最后除以总的时间跨度来得到平均值。这种方法确保了在数据点稀疏的时段，其对最终平均值的影响较小，而在数据点密集的时段，其影响较大。

### 独特优势
`TWA`函数在处理时序数据时具有显著优势：
1.  **准确性**: 对于不规则采样的传感器数据，`TWA`能更真实地反映物理量的平均状态。例如，一个温度传感器在白天每分钟记录一次，而在夜间每小时记录一次，简单的`AVG`会过度加权夜间稀疏的数据点，而`TWA`则能正确反映白天温度变化更频繁的事实。
2.  **抗稀疏性**: 在数据存在缺失或采样率变化的场景下，`TWA`的结果比`AVG`更加稳健和可靠。

## 函数用法示例
以下SQL示例展示了如何在TDengine中使用这些聚合函数，特别是与`GROUP BY`子句的结合。

### 基本聚合查询
```sql
-- 计算表t1中c列的计数、总和、平均值、最大值和最小值
SELECT COUNT(c), SUM(c), AVG(c), MAX(c), MIN(c) FROM t1;

-- 使用TWA函数计算c列的时间加权平均值
SELECT TWA(c) FROM t1;
```

### 结合GROUP BY子句
```sql
-- 按标签(tgcol)分组，计算每个分组中c列的平均值
SELECT AVG(c) FROM stb1 GROUP BY tgcol;

-- 按标签(tgcol)分组，计算每个分组中c列的时间加权平均值
SELECT TWA(c) FROM stb1 GROUP BY tgcol;

-- 结合时间窗口和分组，计算每10分钟内，每个子表的时间加权平均值
SELECT TWA(c) FROM stb1 INTERVAL(10m) GROUP BY TBNAME;
```

## 分布式环境下的计算
在TDengine的分布式架构中，聚合函数的计算过程被设计为可并行和可合并的，以确保高效率和可扩展性。

1.  **分片计算**: 查询请求被分发到存储相关数据的各个vnode（虚拟节点）。每个vnode在其本地数据上独立执行聚合函数，生成一个中间结果。
2.  **结果合并**: 中间结果被发送到执行查询的qnode（查询节点）。对于`COUNT`、`SUM`等函数，qnode只需将各个vnode的中间结果相加即可得到最终结果。对于`AVG`，qnode需要合并总和和计数，然后重新计算平均值。`TWA`函数的中间结果包含面积和时间窗口信息，可以在qnode上进行合并。
3.  **性能考量**: 这种“分片-合并”（Shard-and-Merge）模型极大地减少了网络传输的数据量，并充分利用了集群的并行处理能力。然而，对于涉及大量分组（如`GROUP BY TBNAME`）的查询，合并阶段可能成为瓶颈，因此合理设计数据模型和查询以减少分组数量是优化性能的关键。

## 测试用例验证
TDengine的代码库中包含了大量的自动化测试用例，用于验证每个聚合函数的行为。位于`test/cases/22-Functions/02-Aggregate`目录下的测试文件，如`test_fun_agg_avg.py`和`test_fun_agg_count.py`，通过构建特定的数据集并执行SQL查询，来断言函数的输出结果是否符合预期。
