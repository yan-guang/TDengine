## SELECT语句基础

TDengine的`SELECT`语句遵循标准SQL语法，其基本结构为`SELECT ... FROM ... WHERE`。该语句用于从一个或多个表中检索数据。`SELECT`关键字后跟一个或多个要检索的列名，`FROM`关键字后跟表名，`WHERE`子句用于指定筛选条件。`SELECT`语句的解析由`sql.y`语法文件定义，并通过`createSelectStmt`函数在`parAstCreater.c`中实现，该函数负责创建`SELECT`语句的抽象语法树（AST）节点。

## 核心子句详解

### SELECT子句
`SELECT`子句定义了查询结果中包含的列。它可以包含列名、通配符（`*`）、表达式或函数调用。例如，`SELECT * FROM table`会返回表中的所有列。`SELECT`子句的语法在`sql.y`文件中由`select_list`和`select_item`规则定义。

### FROM子句
`FROM`子句指定了查询的数据源，即表名。TDengine支持普通表、超级表和虚拟表。`FROM`子句的语法在`sql.y`文件中由`cmd`规则定义，例如`cmd ::= SELECT select_list FROM table_name`。

### WHERE子句
`WHERE`子句用于过滤行，只返回满足指定条件的行。它支持各种比较运算符（如`=`、`>`、`<`）、逻辑运算符（如`AND`、`OR`）和特殊运算符（如`LIKE`、`IN`、`BETWEEN`）。`WHERE`子句的语法在`sql.y`文件中由`where_clause_opt`规则定义。

## 时序分析子句

TDengine提供了强大的时序分析功能，通过特定的子句来实现。

### INTERVAL子句
`INTERVAL`子句用于将时间序列数据按固定的时间间隔进行分组，常用于时间窗口聚合。其语法为`INTERVAL(time_interval)`，其中`time_interval`可以是`1s`（秒）、`1m`（分钟）、`1h`（小时）等。例如，`SELECT COUNT(*) FROM table INTERVAL(1m)`会按每分钟统计一次记录数。

### FILL子句
`FILL`子句用于处理时间窗口内没有数据点的情况，即填充缺失值。它通常与`INTERVAL`子句一起使用。支持的填充模式包括：
- `FILL(NONE)`: 不填充，结果中该时间窗口的值为`NULL`。
- `FILL(PREV)`: 使用前一个时间窗口的值进行填充。
- `FILL(NEXT)`: 使用后一个时间窗口的值进行填充。
- `FILL(LINEAR)`: 使用线性插值进行填充。
- `FILL(VALUE, value)`: 使用指定的常量值进行填充。

### SESSION_WINDOW子句
`SESSION_WINDOW`子句用于会话窗口分析。它根据时间间隔将连续的事件分组为一个会话。当两个事件之间的时间间隔超过指定的阈值时，就认为一个会话结束，新的会话开始。其语法为`SESSION(ts, interval)`，其中`ts`是时间戳列，`interval`是会话超时间隔。

### STATE_WINDOW子句
`STATE_WINDOW`子句用于状态窗口分析。它根据某个状态列的值变化来划分窗口。当状态列的值发生变化时，就认为一个窗口结束，新的窗口开始。其语法为`STATE_WINDOW(state_column)`。

### PARTITION BY子句
`PARTITION BY`子句用于将结果集按一个或多个列进行分区。在每个分区内，可以独立地应用聚合函数或窗口函数。这在处理超级表时非常有用，可以按`tbname`（子表名）进行分区，从而对每个子表的数据进行独立分析。

## 聚合函数

TDengine支持多种聚合函数，用于对一组值进行计算并返回单个值。

### 基础聚合函数
- `COUNT(*)`: 返回行数。
- `SUM(column)`: 返回指定列所有值的总和。
- `AVG(column)`: 返回指定列所有值的平均值。
- `MIN(column)`: 返回指定列的最小值。
- `MAX(column)`: 返回指定列的最大值。

### 时序专用聚合函数
- `TWA(column)`: 时间加权平均值（Time-Weighted Average），计算时考虑了数据点之间的时间间隔。
- `DIFF(column)`: 计算相邻数据点之间的差值。
- `DERIVATIVE(column)`: 计算导数，即单位时间内的变化率。
- `IRATE(column)`: 瞬时速率，计算最近两个数据点之间的变化率。

## 选择与标量函数

### 选择函数
- `FIRST(column)`: 返回指定列的第一个非`NULL`值。
- `LAST(column)`: 返回指定列的最后一个非`NULL`值。
- `TOP(column, N)`: 返回指定列中值最大的前N个值。
- `BOTTOM(column, N)`: 返回指定列中值最小的前N个值。

### 标量函数
标量函数对单个值进行操作并返回单个值。TDengine支持丰富的标量函数，包括数学函数（如`ABS`, `SQRT`）、字符串函数（如`LOWER`, `UPPER`）、时间函数（如`NOW`, `TODAY`）等。这些函数的实现位于`scalar.h`和`sclfunc.c`文件中。

## 复杂查询示例

### JOIN操作
TDengine支持表之间的`JOIN`操作，可以将来自多个表的数据组合在一起。以下示例展示了如何对两个表进行内连接：
```sql
SELECT t1.column1, t2.column2 FROM table1 t1, table2 t2 WHERE t1.id = t2.id;
```
相关的测试用例位于`queryJoin.py`中。

### 子查询
子查询是嵌套在另一个查询中的`SELECT`语句。它可以出现在`SELECT`、`FROM`或`WHERE`子句中。以下示例展示了如何使用子查询作为数据源：
```sql
SELECT * FROM (SELECT ts, value FROM table WHERE value > 100) AS subquery WHERE ts > '2023-01-01';
```
相关的测试用例位于`test_subquery_basic.py`和`test_nestedQuery.py`中。

### 函数组合使用
可以将多个函数组合使用以实现复杂的分析。例如，以下查询计算了每个会话的持续时间：
```sql
SELECT ELAPSED(ts, 1s) FROM table SESSION(ts, 10m);
```
相关的测试用例位于`test_fun_agg_elapsed.py`中。
