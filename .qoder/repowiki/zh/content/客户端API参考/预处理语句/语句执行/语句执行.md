## 引言

## 执行流程分析

### 语句执行流程
`taos_stmt_execute`函数是预处理语句执行的核心，负责将已准备和绑定的语句发送到服务器执行。该函数首先进行参数验证，然后调用内部的`stmtExec`函数完成实际的执行逻辑。

```mermaid
sequenceDiagram
participant 应用程序
participant taos_stmt_execute
participant stmtExec
participant launchQueryImpl
participant 服务器
应用程序->>taos_stmt_execute : 调用执行
taos_stmt_execute->>stmtExec : 验证参数并调用
stmtExec->>stmtSwitchStatus : 切换到执行状态
stmtExec->>launchQueryImpl : 启动查询执行
launchQueryImpl->>服务器 : 发送执行请求
服务器-->>launchQueryImpl : 返回执行结果
launchQueryImpl-->>stmtExec : 处理执行响应
stmtExec->>stmtCleanExecInfo : 清理执行信息
stmtExec-->>taos_stmt_execute : 返回执行结果
taos_stmt_execute-->>应用程序 : 返回执行状态
```

### 语句关闭流程
`taos_stmt_close`函数负责释放预处理语句占用的所有资源。该函数首先检查语句是否正在使用绑定线程，如果是，则停止队列并等待线程结束，然后清理SQL信息并释放内存。

```mermaid
sequenceDiagram
participant 应用程序
participant taos_stmt_close
participant stmtClose
participant stmtCleanSQLInfo
应用程序->>taos_stmt_close : 调用关闭
taos_stmt_close->>stmtClose : 验证参数并调用
alt 存在绑定线程
stmtClose->>stmtClose : 停止队列并等待线程结束
end
stmtClose->>stmtCleanSQLInfo : 清理SQL信息
stmtCleanSQLInfo->>stmtCleanSQLInfo : 释放各种缓存和哈希表
stmtCleanSQLInfo-->>stmtClose : 完成清理
stmtClose->>taosMemoryFree : 释放语句内存
stmtClose-->>taos_stmt_close : 返回成功状态
taos_stmt_close-->>应用程序 : 返回关闭结果
```

## 事务管理与错误传播

### 状态转换管理
预处理语句的执行过程受到严格的状态管理，通过`stmtSwitchStatus`函数确保操作的顺序性和正确性。每个语句都有一个状态机，从初始化到准备、绑定、添加批次，最后到执行。

```mermaid
stateDiagram-v2
[*] --> STMT_INIT
STMT_INIT --> STMT_PREPARE : taos_stmt_prepare()
STMT_PREPARE --> STMT_SETTBNAME : taos_stmt_set_tbname()
STMT_SETTBNAME --> STMT_SETTAGS : taos_stmt_set_tags()
STMT_SETTBNAME --> STMT_BIND : taos_stmt_bind_param()
STMT_SETTAGS --> STMT_BIND : taos_stmt_bind_param()
STMT_BIND --> STMT_ADD_BATCH : taos_stmt_add_batch()
STMT_ADD_BATCH --> STMT_EXECUTE : taos_stmt_execute()
STMT_EXECUTE --> STMT_INIT : 执行完成或失败
STMT_INIT --> [*]
```

### 错误传播机制
执行过程中发生的错误通过`STMT_ERR_RET`宏进行传播，确保错误码能够正确返回给调用者。当执行请求返回错误码时，系统会尝试刷新元数据，如果刷新成功则返回重试错误码，否则直接返回原始错误码。

```mermaid
flowchart TD
A[开始执行] --> B{请求成功?}
B --> |是| C[更新影响行数]
B --> |否| D{需要客户端处理错误?}
D --> |是| E[刷新元数据]
E --> F{刷新成功?}
F --> |是| G[返回重试错误码]
F --> |否| H[返回原始错误码]
D --> |否| I[返回原始错误码]
C --> J[清理执行信息]
G --> J
H --> J
I --> J
J --> K[返回执行结果]
```

## 资源清理机制

### 执行信息清理
`stmtCleanExecInfo`函数负责清理执行过程中产生的各种信息，包括数据块哈希表、当前数据块、绑定信息等。根据是否需要保留表信息和是否深度清理，采取不同的清理策略。

```mermaid
flowchart TD
A[开始清理执行信息] --> B{是否为交错模式?}
B --> |是| C{是否深度清理?}
C --> |是| D[清理数据块哈希表]
C --> |否| E[重置表列索引]
C --> |否| F[重置队列表缓冲区]
C --> |否| G[清除表行数据哈希]
B --> |否| H{是否为查询类型?}
H --> |否| I[释放请求结果]
H --> |是| J{是否深度清理?}
J --> |是| I
J --> |否| K[跳过清理]
I --> L[遍历数据块哈希表]
L --> M{是否有更多数据块?}
M --> |是| N[获取数据块]
N --> O[销毁数据块]
O --> P[从哈希表中移除]
P --> M
M --> |否| Q[清理数据块哈希表]
Q --> R[销毁当前表数据]
R --> S[清理绑定信息]
S --> T[返回成功]
```

### SQL信息清理
`stmtCleanSQLInfo`函数负责清理SQL相关的所有信息，包括绑定信息、查询结果字段、SQL字符串、查询对象、表缓存等。该函数确保在语句关闭或重置时，所有分配的资源都被正确释放。

```mermaid

L --> M[释放绑定标签]
M --> I
I --> |否| N[清理表缓存哈希表]
N --> O[清理执行信息]

P --> Q[清理交错信息]
```

## 批量插入与查询执行模式

### 批量插入执行模式
通过分析`examples/c/prepare.c`中的代码，可以了解如何使用预处理语句实现高效的批量插入。该模式首先初始化语句，准备插入SQL，然后循环绑定参数并添加批次，最后执行插入操作。

```c
// 从prepare.c提取的批量插入模式
TAOS_STMT *stmt = taos_stmt_init(taos);
taos_stmt_prepare(stmt, "insert into m1 values(?,?,?,?,?,?,?,?,?,?,?)", 0);

for (int i = 0; i < 10; ++i) {
    // 更新绑定参数
    v.ts += 1;
    v.b = (int8_t)i % 2;
    // ... 其他字段更新
    
    taos_stmt_bind_param(stmt, params);
    taos_stmt_add_batch(stmt);
}

if (taos_stmt_execute(stmt) != 0) {
    printf("failed to execute insert statement.\n");
}
```

### 查询执行模式
查询执行模式与插入类似，但需要在执行后使用`taos_stmt_use_result`获取结果集，然后通过`taos_fetch_row`逐行读取结果。

```c
// 从prepare.c提取的查询执行模式
taos_stmt_prepare(stmt, "SELECT * FROM m1 WHERE v1 > ? AND v2 < ?", 0);
taos_stmt_bind_param(stmt, params + 2);

if (taos_stmt_execute(stmt) != 0) {
    printf("failed to execute select statement.\n");
}

TAOS_RES *result = taos_stmt_use_result(stmt);
TAOS_ROW row;
while ((row = taos_fetch_row(result))) {
    // 处理每一行数据
    taos_print_row(temp, row, fields, num_fields);
    printf("%s\n", temp);
}
```

### 异常处理策略
系统采用分层的异常处理策略，从参数验证、状态检查到执行错误处理，确保每个环节的错误都能被正确捕获和处理。开发者应检查每个API调用的返回值，并根据错误码采取相应的恢复措施。

```mermaid
flowchart TD

B --> |是| D{当前状态允许?}
D --> |否| E[设置语句API错误码]
D --> |是| F[执行操作]
F --> G{操作成功?}
G --> |否| H[传播错误码]
G --> |是| I[返回成功]
C --> J[返回错误]
E --> J
H --> J
```
